Tutorial data
=============

Most prepared AnnData objects used by the tutorials are archived in the
`AnnData for scBIOT analysis Figshare collection
<https://figshare.com/articles/dataset/Anndata_for_scBIOT_analysis/30671669>`_.
Each notebook downloads its input to ``SCBIOT_TUTORIAL_DATA`` and uses a stable
direct URL. Files that are not in that collection link to the original data
provider instead of relying on an undocumented local cache.
